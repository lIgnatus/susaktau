# Сусак-тау: многослойный памятник

Слайд-шоу к защите исследовательской работы «Гора Сусак-тау как многослойный памятник истории и природы Альшеевского района». Конкурс «Отечество: история, культура, природа, этнос», номинация «Летопись родного края», 2026. Автор Елизавета Сальникова, руководители С. В. Попков и З. Я. Ахметзянова.

Сайт: https://lignatus.github.io/susaktau/

![Все слайды](Все%20слайды.jpg)

## Как листать

Фоном идут ролики с дрона над Сусак-тау, у каждого слайда свой фрагмент. Внизу тринадцать плашек-слайдов: после показа плашка окрашивается в цвет своего слоя.

- «Старт» включает полный экран, первый слайд и таймер на 7 минут.
- «Назад» и «Вперёд», стрелки, пробел, колёсико мыши или пульт-кликер.
- На телефоне листать свайпом, плашки внизу прокручиваются лентой.
- Клавиша T показывает текст выступления к слайду, F включает полный экран.
- Адрес с номером, например `#8`, открывает нужный слайд.

Папку можно скачать и открыть `index.html` без интернета.

## Откуда материалы

Оформление взято с туристического портала Альшеевского района: шрифт Tinos, гравюра горы на плашках, цвета логотипа «Гряда». Видео с дрона из материалов портала, замедлены вдвое. Схема района: рельеф Mapzen Terrarium, объекты © участники OpenStreetMap. Фото находок, картина «Туктаровская мельница» (1976, музей Чураевской школы) и снимок места находки из архива руководителя. Кадр клипа AY YOLA «Ural Vasyaty» по публикации Sterlitamak1.ru от 20.07.2025.

Все тексты слайдов лежат в `js/slides.js`.
